This is my own ray tracer build from scratch! I worked on a ray tracer in my computer
graphics course, but I wanted to develop my own to practice developing a large program from
the ground up. I will be implementing many of the features of a ray tracer such as Lambertian diffuse shading,
recursive multi-bounce path tracing, anti-aliasing, and many more!

This is a fun personal project since I enjoy the challenge that computer graphics provides.
It will also be a way for me to sharpen my C++ skills, as there will be many C++ concepts that
are required in the development of a project like this.
